# 固件软件初步盘点

日期：2026-11-07。来源为离线提取的官方 R2D 稳定版 2.24.11 的 `/usr/lib/opkg/status`；目标设备的固件版本为 2.25.209。以下是固件样本包数据库记录，不代表已验证当前运行进程的实际版本、厂商补丁或漏洞可利用性。

| 组件 | 样本版本 | 初步优先级 | 约束 |
| --- | --- | --- | --- |
| Samba | 4.0.21-1 | 高 | 小米授权、摄像机、磁盘热插拔和 WiFi 管理集成 |
| OpenSSL | 1.0.1j-1 | 高 | 多进程共享 ABI，不能覆盖系统库；[上游支持状态](https://www.openssl-library.org/news/vulnerabilities-1.0.1/index.html) |
| curl | 7.33.0-1 | 中高 | 依赖 TLS、CA 和厂商脚本；[上游版本漏洞列表](https://curl.se/docs/vuln-7.33.0.html)，须核对厂商补丁 |
| dnsmasq | 2.71-4 | 高但涉及网络核心 | DNS/DHCP/IPv6、脚本及运行配置必须兼容 |
| BusyBox | 1.19.4-6 | 研究优先 | 被 init 和大量脚本调用，系统级替换风险高 |
| uhttpd | 2012-10-30 snapshot | 研究优先 | 路由管理界面和厂商 Lua API |
| ubus/netifd/firewall | 2014 snapshots | 研究优先 | 管理、无线与联网依赖，不适宜独立替换 |

先完成目标设备只读清单、监听端口、依赖与厂商补丁核实，再按可隔离测试的方式构建；不能根据版本号单独断定某个 CVE 可利用。优先考虑安装到独立目录的客户端与服务，避免改写动态链接库、固件配置和核心服务。旧内核和 uClibc 的安全维护无法因更新单个应用而自动获得保障。
