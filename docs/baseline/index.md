# S0：现场基线与行为合同

本目录是 [SMB 开发计划](../plans/smb-development.md) 第一阶段 S0 的交付集合，基线日期 2026-11-07。它只记录已取得的证据和未知项，不构成可安装方案，也不表示任何厂商功能已经完成移植。

## 证据等级

| 标记 | 含义 |
| --- | --- |
| 现场 | 2026-11-07 对现场 R2D（ROM 2.25.209）的只读检查，原始记录保存在项目研究档案，不随本仓库分发 |
| 反汇编 | 对现场 `/usr/sbin/samba_multicall` 的静态分析；地址是代码定位，不是恢复出的原函数名 |
| 样本 | 官方 ROM 2.24.11 的离线拆包文件；不等于现场 2.25.209 |
| 隔离 | QEMU、独立端口、合成账户与合成文件的实验 |
| 上游 | samba-team 对应标签的公开源码或提交 |
| 待确认 | 没有直接证据，必须保留在支持限制中 |

现场记录中的设备地址、MAC、序列号、共享清单和账号信息不在本仓库出现；需要复现时由维护者在本机档案中核对。

## S0 状态

已完成：把分散在研究档案中的现场观察、反汇编结论、ROM 样本事实、隔离实验结果收拢为可审计的行为合同，并为本轮引用的散列、地址和版本做了本机复核（见 [evidence.md](evidence.md)）。

未关闭：以下三项没有本轮新的观测数据，必须继续标为待确认，不能被后续阶段的“模型通过”或“构建成功”替代：

1. 现场运行基线：实际可用内存、磁盘与文件系统、运行中的进程参数、完整监听端口、运行库散列。
2. 权限链的完整顺序：hosts allow/deny、IPC$、连接级检查、文件权限与拒绝缓存的相互关系。
3. 地址到 MAC 的解析方式，以及 IPv6、跨网段、MAC 变更和会话中撤销权限的行为。

因此 S0 的文档骨架与证据索引已交付，但“现场基线”本身仍未完整；S1 的平台基线应以补采后的数据为准。缺设备或无法观测的功能继续保留在 [unknowns.md](unknowns.md) 的支持限制中。
