# S0：现场基线与行为合同

本目录是 [SMB 开发计划](../plans/smb-development.md) 第一阶段 S0 的交付集合，基线日期 2026-11-07。它只记录已取得的证据和未知项，不构成可安装方案，也不表示任何厂商功能已经完成移植。

## 证据等级

| 标记 | 含义 |
| --- | --- |
| 现场 | 2026-11-07 对现场 R2D（ROM 2.25.209）的只读检查，原始记录保存在项目研究档案，不随本仓库分发 |
| 反汇编 | 对现场 `/usr/sbin/samba_multicall` 的静态分析；地址是代码定位，不是恢复出的原函数名 |
| 样本 | 官方 ROM 2.24.11 的离线拆包文件；不等于现场 2.25.209 |
| 隔离 | QEMU、独立端口、合成账户与合成文件的实验 |
| 上游 | samba-team 对应标签的公开源码或提交 |
| 待确认 | 没有直接证据，必须保留在支持限制中 |

现场记录中的设备地址、MAC、序列号、共享清单和账号信息不在本仓库出现；需要复现时由维护者在本机档案中核对。

## S0 状态

已完成：把分散在研究档案中的现场观察、反汇编结论、ROM 样本事实、隔离实验结果收拢为可审计的行为合同；2026-11-07 以只读方式登录现场 R2D（能力上限已确认：SSH 可用、Samba 正在服务真实客户端），补齐了内存、磁盘与文件系统、进程参数、完整监听端口、运行库散列、权限相关配置与 MAC 解析链路，详见 [device.md](device.md) 的“S0 现场采集”与 E9。

仍无法观测、已单列原因的项目：`/tmp/loginMac.cfg` 的成员与生命周期、完整检查顺序、会话中撤销权限的即时性、列表写入者、真实摄像机行为、MAC 变更与 IP 复用。这些不是“已知为空”，而是只读约束下观测不到，继续保留在 [unknowns.md](unknowns.md)。

S0 在这一口径下关闭：可观测项均已验证并留证，不可观测项均有明确原因，没有用推断填充。
