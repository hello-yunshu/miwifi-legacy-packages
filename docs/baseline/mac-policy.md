# MAC 权限真值表

本文件只描述已从厂商二进制恢复的核心分支，不是完整访问控制。离线模型 [tools/policy.py](../../tools/policy.py) 只实现此核心分支，不能用于生产。证据编号见 [evidence.md](evidence.md)。

## 两个列表

| 列表 | 路径 | 写入者与生命周期 |
| --- | --- | --- |
| 登录设备 | `/tmp/loginMac.cfg` | 临时路径；写入者、写入时机与格式未确认 |
| 非登录设备 | `/userdisk/datacenterConfig/nonLoginMac.cfg` | 持久路径；写入者、格式与删除时机未确认 |

现场只读检查时，Ubuntu 客户端的 MAC 位于 nonLogin 列表，login 列表不存在；sysapi 的 `pridisk` 返回 `no`。这两个字段不能简单等同，二进制显示 nonLogin 列表同样参与“整盘”分支。

## 查找与决策

| 步骤 | 行为 | 地址 | 等级 |
| --- | --- | --- | --- |
| 列表查找 | 检查文件存在、打开、逐行读取、去掉行末换行、比较 MAC；命中返回 0，未命中或文件不可读返回 -1 | `0x1ca140` | 反汇编 |
| 决策入口 | 先把传入 MAC 转小写；先查 login 列表，未命中再查 nonLogin 列表；任一命中进入“整盘”分支 | `0x1ca258` | 反汇编 |
| 上层接入 | 由远端地址取得 MAC 并传入共享编号；共享编号 -1（连接级）或以 IPC$ 开头的名称被特殊放行到后续逻辑 | `0x1cab08` | 反汇编 |
| 其他调用点 | `0x305d64`、`0x30b5f0`、`0x323aa0`、`0x36c988`、`0x36c9bc`，另有 `0x1cad7c` | 见左 | 反汇编 |
| 日志 | `allow_access_internal_from_macfilter, mac : %s, snum : %d` | 二进制字符串 | 反汇编 |

核心分支（“整盘”指选择非 browseable 共享）：

```text
full_disk = 命中 login 列表 或 命中 nonLogin 列表
if full_disk:
    allow = 共享不 browseable
else:
    allow = 共享 browseable
```

## 真值表（核心分支）

| 在 login | 在 nonLogin | 共享 browseable | 核心结果 | 等级 |
| --- | --- | --- | --- | --- |
| 是 | 任意 | 是 | 拒绝 | 反汇编 |
| 是 | 任意 | 否 | 允许 | 反汇编 |
| 否 | 是 | 是 | 拒绝 | 反汇编 |
| 否 | 是 | 否 | 允许 | 反汇编 |
| 否 | 否 | 是 | 允许 | 反汇编 |
| 否 | 否 | 否 | 拒绝 | 反汇编 |

推论与边界：

- 输入 MAC 被转小写，但列表行按原样比较；若列表含大写条目则不会命中。这是从代码路径得出的推论，未在设备上构造验证。
- 列表文件缺失或不可读时，查找返回未命中；未授权客户端因此只能看到 browseable 共享，不会因解析失败获得隐藏整盘共享。等级：反汇编；未做负向实测。
- 两个列表按“任一命中”合并，不区分登录/非登录的权限差异；文件名的语义不能代替代码分支。
- 该分支不包含 hosts allow/deny、共享级 `valid users`、文件系统权限、IPC$ 例外和连接级检查的先后顺序。

## 未恢复的路径

| 问题 | 现状 | 影响 |
| --- | --- | --- |
| 远端 IP 到 MAC 的解析方式 | 未恢复（ARP、邻居表或 ubus 均有可能） | 无法判断跨网段、IPv6、无邻居记录时的身份选择 |
| 未知 MAC / 解析失败 | 核心分支按“未命中”处理，但上层是否提前拒绝未确认 | 可能影响拒绝语义 |
| 会话中撤销权限 | 未测试 | 无法声明撤销立即生效 |
| MAC 变更或 IP 复用 | 未测试 | 会话缓存与重连行为未知 |
| 列表格式细节 | 仅知逐行比较；空行、空格、注释、重复项、权限位未验证 | 可能影响现场文件可解析性 |
| 列表写入者与生命周期 | 未确认 | 无法保证升级后授权仍被维护 |
| 与 sysapi `pridisk` 的关系 | 现场观察与代码分支不能简单对齐 | 不能据此推断其他共享的授权 |

MAC 可伪造，这一兼容层不应被宣传为强身份认证。完整真值表与负向集成测试属于 S3，不因离线模型测试通过而完成。
