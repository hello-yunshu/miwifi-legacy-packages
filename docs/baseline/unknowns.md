# 未知项与支持限制

按“是否阻断当前阶段”和“影响哪个阶段”分类。任何一项都不能用其他阶段的成功替代。

## 阻断 S0 完整性的现场缺口

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |
| 实际可用内存 | 无法判断新版 Samba 与私有依赖的内存余量 | 只读采集 `/proc/meminfo` 并记录负载 |
| 磁盘与文件系统 | 无法判断共享路径的文件系统、挂载选项与大文件行为 | 只读采集 `df`、`mount`、`/proc/self/mounts` |
| 运行中进程参数与 PID 文件 | 无法建立启动/停止/重载的真实基线 | 只读采集 `ps`、`pidof` 与 PID 目录 |
| 完整监听端口（139/445 等） | 无法确认 NetBIOS 与发现行为 | 只读采集监听端口 |
| 运行库散列 | 无法核对私有依赖与系统库的来源 | 只读采集 libc/libpthread/解释器散列 |

## 阻断 S1 的构建前提

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |
| 最新稳定版锁定 | 计划基线写的是 4.25.1，但未重新核实发布与签名 | 重新核对上游发布记录、源码散列与签名 |
| SDK 与固件再分发权限 | 无法把工具链或固件放入公开构建与缓存 | 完成许可证与再分发核查，或仅本地自备 |

| 干净构建证据 | 现有 4.23.13 是增量修复构建，不是干净重跑 | 从全新源码和空输出目录构建并记录依赖 |

## 阻断 S2 的客户端与回归

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |
| Windows 11 设备 | 不能声明 Windows 11 兼容 | 取得设备后测试签名、加密与访客策略 |
| Emby 完整播放 | 只验证目录、存在检查和 1 MiB 读取，未验证拖动与完整播放 | 真实媒体播放并记录协议/加密状态 |
| 真实固件内核 | QEMU 使用宿主内核，未验证 Linux 2.6.36 | S6 实机受控实验 |
| 性能与资源 | 无实机吞吐与 CPU/内存基线 | S6 按原厂基线与设备余量测量 |

## 阻断 S3 的权限适配

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |
| 远端地址到 MAC 的解析方式 | 无法判断跨网段、IPv6、邻居缺失时的身份 | 恢复调用链并用合成客户端做正负测试 |
| 完整检查顺序 | hosts allow/deny、IPC$、连接级、文件权限与 MAC 分支的先后未知 | 反汇编补齐并建立覆盖矩阵 |
| 两个列表的写入者与生命周期 | 升级后授权是否继续被维护无法保证 | 定位写入方并观察创建/更新/删除 |
| 列表格式细节 | 空行、空格、大小写、重复项、权限位未验证 | 构造合成列表做解析回归 |
| 会话中撤销权限 | 无法声明撤销立即生效 | 对照原厂测试已连接会话 |
| MAC 变更与 IP 复用 | 会话缓存与重连行为未知 | 受控客户端测试 |
| 原厂安全行为差异 | 无法判断移植后是否静默改变规则 | 与现场逐项对照，差异写入支持限制 |

## 阻断 S4 的摄像机适配

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |
| 时间参数语法、单位、时区与时间来源 | 无法正确复刻时间窗 | 恢复配置解析与时间调用，构造边界测试 |

| 真实摄像机 | 没有实际写入与回放证据 | 取得设备后测试，否则保持未验证 |

## 阻断 S5 的管理与生命周期

| 未知项 | 影响 | 关闭条件 |
| --- | --- | --- |

| 插件与手机 App 全链路 | 未验证每个管理按钮 | 真实 App 与外围设备测试 |

## 支持限制（当前必须公开声明）

1. 仅有研究阶段的文档与离线模型，**没有可安装包**，不得替换路由器原厂程序。
2. 首版只针对 R2D 2.25.209；不从其他型号或版本号相似性推导兼容。
3. 未验证 Windows 11；macOS 与 Emby 的首轮结果也不能外推为 Windows 11 策略兼容。
4. 摄像机功能未验证；不得声称完整替代原厂只读行为。
5. 小米设备授权、管理 App、电视/DLNA 联动均未完成端到端验证。
6. MAC 可伪造，MAC 兼容层不是强身份认证。
7. 公开仓库不含 SDK、固件、厂商程序或厂商配置原文；外部无法逐字节复现研究档案。
8. 所有隔离实验使用宿主内核，未证明 Linux 2.6.36 运行时兼容。
9. 研究档案中的现场摘要已脱敏；设备地址、MAC、共享清单与账号不进入仓库。

- S1 及之后：尚未开始；不得因本文件的整理工作而进入下一阶段。
