## 使用约定

- 目录名以采集日期开头；同一天多轮采集用后缀区分主题。
- 原始输出不改写；结论写在 `README.md` 或同名 `.md` 里，便于把“事实”和“推断”分开。
- 涉及敏感值的记录（host key 指纹、MAC、口令）按需脱敏，脱敏处标注原值位置。
